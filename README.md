# 🐰 うさうさ研修工房｜研修スイート
### Training Suite — 6つの道具を、一冊に。

**研修の準備から運営、振り返りまでをサポートする無料ツール集です。**

研修担当者・講師・教育関係者の日々の業務を、少しでも便利にすることを目指して開発しました。

---

## 🌸 1. 概要

研修スイートは、研修や勉強会で役立つ6つの機能をまとめた個人開発ツールです。

- 01｜勉強会のご案内
- 02｜時間割
- 03｜座席メモ
- 04｜ワークショップ
- 05｜理解度クイズ
- 06｜根本原因分析

研修準備にかかる手間を減らし、参加者と向き合う時間を増やすことを目指しています。

## 🖥️ 2. 利用環境

| 項目 | 推奨環境 |
|---|---|
| デバイス | PC |
| OS | Windows等 |
| ブラウザ | Google Chrome |
| 利用料金 | 無料 |
| バージョン | v1.5.0 PRO |

※PC環境での利用を推奨します。

## 🚀 3. 利用方法

本ツールには、2つの利用形式があります。

### ① Claudeアーティファクト版
Claude上でツールを開いて利用する形式です。

### ② HTML版
HTMLファイルをブラウザで開いて利用する形式です。

Google Chromeでの利用を推奨します。

**PDF印刷機能はHTML版のみ対応しています。**

## 📖 4. 基本的な使い方

1. 利用したい形式（アーティファクト版・HTML版）を選びます。
2. 使用したい機能を選択します。
3. 画面の案内に従って必要事項を入力します。
4. 作成した内容を確認し、研修や勉強会に活用します。

## ⚠️ 5. 注意事項

- 本ツールは無料で利用できる個人開発ツールです。
- Claudeを活用して開発していますが、Anthropic社およびClaudeの公式製品・公式提供ツールではありません。
- PDF印刷はHTML版のみ対応しています。
- 推奨環境以外では、表示や動作が異なる場合があります。
- 業務上の機密情報や個人情報を入力する場合は、利用環境や情報管理方針を確認してください。
